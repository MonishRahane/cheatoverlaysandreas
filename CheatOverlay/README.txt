Cheat Overlay has two ways to send GTA SA cheats.

A) CHEAT KEYBOARD (no root, no Shizuku)
 1. Open the app > "KEYBOARD MODE 1" > switch on "Cheat Keyboard" in the list.
 2. Open GTA SA. Bring up the keyboard (or use "KEYBOARD MODE 2" / the keyboard
    icon in the nav bar) and choose Cheat Keyboard.
 3. Tap a cheat preset or type letters.
 Works only if the game accepts text/keyboard input.

B) FLOATING OVERLAY (needs root or Shizuku)
 1. Tap 1 (overlay permission), 2 (check key access), 3 (start overlay).
 2. Tap the floating bubble in the game, tap a cheat. ✕ closes it.
