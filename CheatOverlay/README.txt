BUILD (no coding needed)
1. Install Android Studio (free) on a PC.
2. File > Open > select this CheatOverlay folder. Let Gradle sync finish.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Find app-debug.apk in app/build/outputs/apk/debug/ and copy it to your phone.

PHONE SETUP
1. Install Shizuku, start it with Wireless debugging.
2. Install the APK, open it, tap buttons 1, 2, 3 in order.
3. Open GTA SA, tap the floating bubble, tap a cheat.
